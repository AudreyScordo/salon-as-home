# GitHub Pages

Ce dossier sert uniquement d'entree iPhone avec le bon logo.

Pages prevues :
- `/` : accueil simple
- `/reserver/` : ouvre la page cliente Apps Script
- `/admin/` : ouvre la page admin Apps Script

Mise en ligne :
1. Cree un depot GitHub public.
2. Depose le contenu de ce dossier a la racine du depot.
3. Dans `Settings > Pages`, choisis `Deploy from a branch`.
4. Selectionne la branche `main` et le dossier `/(root)`.
5. Attends l'URL GitHub Pages.

Ensuite sur iPhone :
- pour la reservation, ouvre `https://ton-compte.github.io/ton-depot/reserver/`
- pour l'admin, ouvre `https://ton-compte.github.io/ton-depot/admin/`
- puis `Partager > Sur l'ecran d'accueil`
